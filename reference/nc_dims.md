# NetCDF dimension

Get information about the dimensions in a NetCDF source.

## Usage

``` r
nc_dims(x, ...)

# S3 method for class 'character'
nc_dims(x, ...)

# S3 method for class 'NetCDF'
nc_dims(x, ...)

# S3 method for class 'ncdf4'
nc_dims(x, ...)
```

## Arguments

- x:

  file address or handle

- ...:

  ignored
