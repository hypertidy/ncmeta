# NetCDF variables

Generate a table of all variables.

## Usage

``` r
nc_vars(x, ...)

# S3 method for class 'character'
nc_vars(x, ...)

# S3 method for class 'NetCDF'
nc_vars(x, ...)
```

## Arguments

- x:

  filename or handle

- ...:

  ignored currently

## Value
